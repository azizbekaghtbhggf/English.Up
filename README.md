# English Up

Ingliz tilini 100 kunda o‘rganish sayti (o‘zbek tilida): kunlik darslar, so‘z testi, imlo mashqi, takrorlash, imtihonlar, sertifikat, sovg‘alar va sandiq.

## Fayllar
- `index.html` — sahifa tuzilishi
- `style.css` — dizayn va animatsiyalar
- `script.js` — barcha mantiq va darslar

## Ishga tushirish
`index.html` ni brauzerda oching (uchala fayl bitta papkada turishi kerak).
Progress brauzerning `localStorage` xotirasida saqlanadi.
